# Архитектура моста NerveForge (Arena.ai ↔ PC & Android)

**NerveForge** спроектирован как высокопроизводительный, легковесный мост (шлюз-приёмник), связывающий агентов платформы **Arena.ai** (работающих в облачных изолированных контейнерах) с локальным физическим устройством разработчика (**Linux**, **Windows 10/11**, **Android / Termux**).

```
+--------------------------------------------------------------------------------------------------+
|                                      ПОТОКИ ДАННЫХ И КОМАНД                                      |
+---------------------+             +--------------------+             +---------------------------+
|      Arena.ai       |  (HTTPS)    | Туннель Cloudflare |  (Loopback) |  Устройство (NerveForge)  |
|    (Agent Mode)     | <=========> |     / Tailscale    | <=========> |  • Linux (Ubuntu/Mint)    |
| Облачный контейнер  |  Bearer Auth|  Авто-публикация   |  127.0.0.1  |  • Windows 10/11          |
|      с агентом      |             |     URL-адреса     |  :8766      |  • Android (Termux)       |
+---------------------+             +--------------------+             +---------------------------+
```

## Ключевые компоненты

1. **HTTP Bridge (`src/nerveforge/bridge.py`):**
   * Принимает входящие запросы от Arena.ai через защищённый туннель с авторизацией по Bearer-токену.
   * Обрабатывает запросы в асинхронном пуле воркеров (`concurrent.futures.ThreadPoolExecutor`) с поддержкой сокетов `TCP_NODELAY`.
   * Предоставляет эндпоинты самодокументирования (`/api/docs`, `/llms.txt`, `/api/agent-prompt`) для моментальной ориентации ИИ-моделей.
   * Маршрутизирует вызовы на раннер терминала, файловый менеджер и обработчики конфигураций.

2. **Кроссплатформенный слой (`src/nerveforge/platform_support.py`):**
   * Автоматически распознаёт тип операционной системы: Linux, Windows, Android (Termux).
   * Выбирает доступные оболочки: Bash, Zsh, Sh, PowerShell, CMD.
   * Распознаёт доступность специализированных API (например, `termux-api` на Android).

3. **Shell Runner полного доступа (`src/nerveforge/uzhas_manager.py`):**
   * Запускает системные команды в целевой оболочке с заданным таймаутом и рабочей папкой (`cwd`).
   * Поддерживает параллельное выполнение задач, настраиваемые лимиты (до 40 МБ команд / 50 МБ вывода).
   * Реализует корректную остановку деревьев дочерних процессов (`killpg` на Linux/Android, `taskkill /T /F` на Windows).

4. **Менеджер туннелей (`src/nerveforge/tunnel.py`):**
   * Автоматически поднимает временный исходящий туннель Cloudflare Quick Tunnel (`*.trycloudflare.com`) или Tailscale Funnel (`*.ts.net`).
   * Позволяет переключать провайдера туннеля на лету прямо из веб-панели управления.

5. **Интеграция с Unity (`src/nerveforge/workspace_manager.py`):**
   * Предоставляет анонимные эндпоинты `/api/public/scripts` и `/api/public/assets` для мгновенной заливки C#-скриптов и шейдеров в директорию `Assets` открытого проекта Unity.

6. **Локальная веб-панель (`static/`):**
   * Локальный дашборд разработчика с мониторингом подключений, веб-терминалом, файловым менеджером, переключателем туннелей и журналом событий.
