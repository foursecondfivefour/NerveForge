# Security policy — NerveForge 7.0.1

NerveForge намеренно открывает локальную машину через публичный туннель. Bearer-токен — это учётные данные, а не граница безопасности. Не публикуйте его в issues, скриншотах, логах чата или примерах конфигурации. Локальная панель получает токен только с loopback-адреса `127.0.0.1:8767/bootstrap`; браузер хранит его в `localStorage` до нажатия «Забыть».

## Туннели

- По умолчанию выбирается **Tailscale Funnel** (`tailscale funnel --bg --https=443 <port>`). Он публичен: любой, кто знает `*.ts.net`-адрес, попадает на панель. Защита — только bearer-токен и явное включение полного доступа.
- **Cloudflare Quick Tunnel** — резервный вариант; включается только если Tailscale недоступен или указан `--tunnel cloudflared`.
- `--tunnel none` оставляет только `127.0.0.1`.
- `--keep-funnel` сохраняет Funnel после выхода; по умолчанию приложение выполняет `tailscale funnel reset`.
- Убедитесь, что Tailscale Funnel разрешён в ACL tailnet (`autogroup:member` по умолчанию) и включены MagicDNS + HTTPS.

## Полный доступ

`POST /api/full-access/config` (bearer + точная фраза `yesiknow`) включает произвольный shell **удалённо** — это осознанное изменение по сравнению с 6.x, где активация была только локальной. Фраза защищает от случайного нажатия, но не является second factor: если злоумышленник знает токен и адрес, он может отправить ту же фразу.

После включения:
- команды выполняются без песочницы и без очереди подтверждений, с произвольным `cwd`;
- на Linux доступен явный `sudo: true` через `sudo -n`; на Windows повышение не запрашивается, но elevated-процесс передаёт административные права всем детям;
- действуют максимальный таймер (1–1440 мин), idle 10 мин, лимит 10 запусков/мин и quick-off с убийством дерева процессов;
- аудит пишет время, ID, shell и SHA‑256 команды, но не сам текст и не вывод.

## Анонимная загрузка Unity

`POST /api/public/scripts` и `/api/public/assets` остаются без токена. Любой, кто знает адрес, может создать новый `.cs`/`.shader` в корне рабочей папки (64 KiB, 5/мин, 30/час, без перезаписи). **Unity компилирует код и editor-скрипты могут выполняться автоматически.** Rate limits — не аутентификация. Если загрузка не нужна, удалите роуты в отдельной ревизии.

## Рекомендации

- Выделенный ПК/VM, без важных данных и без корпоративной сети.
- Не запускайте NerveForge и Unity от администратора без крайней необходимости.
- Держите полный доступ выключенным, когда им не пользуетесь; ротируйте токен при любом подозрении (перезапуск создаёт новый).
- Не публикуйте URL Funnel/ Quick Tunnel.
- Сообщайте об уязвимостях приватно, без токенов и реальных адресов.


## Исправленный обход bootstrap (7.0.1)

В 7.0.0 маршрут `/api/local-bootstrap` доверял клиентским заголовкам `Host` и `Origin`. Tailscale Funnel передаёт их как есть, поэтому удалённый клиент мог подставить `127.0.0.1:8766` и получить bearer-токен. Теперь этот маршрут на публичном слушателе всегда возвращает `403`; токен выдаёт только отдельный loopback-слушатель `127.0.0.1:8767` с проверкой Origin локальной панели. Полный доступ по-прежнему включается удалённо через `/api/full-access/config` с кодовой фразой.
