# NerveForge visual identity

**Name:** NerveForge  
**Tagline:** Build boldly. Ship cleverly.  
**Mark:** an angular forge-pillar; its vertical rails suggest both classical fluting and code/circuit tracks, while the acid-lime chevron signals nerve and forward motion.

## Palette

- Charcoal: `#222127`
- Warm ivory: `#F7F2E5`
- Acid lime: `#C9FF3F`
- Wordmark olive: `#759A00`

Use the mark on light or warm-ivory surfaces for maximum contrast. The lockup is supplied as PNG and SVG; the isolated transparent mark is also available as PNG for app icons and UI headers.

The visual direction references the broad classical-pillar idea discussed in Arena's public rebrand article. NerveForge is an independent project, is not affiliated with Arena, and does not use Arena's name or artwork.
